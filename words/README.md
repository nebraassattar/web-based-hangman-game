# Required game resources

The instructor's `easy.txt`, `medium.txt`, and `hard.txt` are not present yet.
Place the verified instructor files here, one ASCII word per line. Record their
source when supplied. The loader trims whitespace, lowercases entries, skips
blank lines, removes duplicates, and rejects invalid or empty lists.

No substitute production lists have been created. Unit tests generate small
synthetic lists in temporary directories; they are test data only.
